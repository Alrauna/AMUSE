# Historical records

Everything in this folder is a dated record. `plans/`, `specs/`, `investigations/`, and `audits/` state what was designed, decided, or observed at their date.

A record does not authorize new subsystems, new work, commits, or changes to the correctness contract. Status words such as "today", "current", or "not implemented" describe the date of the record, not the present.

`docs/architecture/vision.md` defines the long-term direction. Current code establishes what exists. When a record conflicts with either, the record is history.
