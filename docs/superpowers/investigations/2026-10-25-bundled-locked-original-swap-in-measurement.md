# Bundled locked original swap-in measurement

Status as of 2026-10-27. This record holds the gated real lock acceptance run of the two bundled 9.3 rows on the dev project of this repository. It is the stage 4 measurement of the bundled locked original admission design (Y9, Y10).

Privacy note. This record names no machine, account, port, editor instance, or private avatar. Test names, package names, and refusal sentences are product content. Every run in this file ran in the dev editor instance of this repository. No test ran in the private Census Lab project.

## 1. Question

Can one real vendor lock per bundled 9.3 row shape align through the production aligner, clone, restore, pass the seventh fact and the consistency check, and swap in through the production service, with per-phase times recorded?

## 2. Answer

No, as of 2026-10-27. All ten gated cases locked successfully and cleaned up. Every case refused in the aligner phase, so no clone, restore, seventh fact, consistency check, or swap-in ran. Stage 4 does not hold on 2026-10-27. Stage 7 stays out of reach.

Every observed refusal sentence is one the aligner rules produce. The refusals are fixed sentences of the closed rule set. They are coverage gaps, not crashes, not invariant failures, and not false positives.

## 6. Observed refusal sentences, 2026-10-27

Two distinct sentences fired across the ten cases.

### 6.1 Neither outcome of a block matches the generated text.

Nine cases refused with this sentence. Six are Toon cases and three are Two Pass cases.

- The aligner reports the Toon cases at original line 15882 and the Two Pass cases at original line 15980. Both lines hold the first guard of the copied Unity indirect specular helper, a guard on a Unity built in projection keyword.
- The sentence is the block alignment refusal. Its fixed text lives at `Editor/Semantics/Poiyomi/PoiyomiLockedSourceAlignment.cs:82`. The walk throws it at two sites in the block resolution of the same file, at line 1024 when both block outcomes refuse inside their trials, and at line 1102 when every tie candidate dies inside the lookahead. The reported sentence does not name which of the two sites fired, so the record names both.
- The spec rules produce this sentence. The block rules resolve a guard with two hypotheses and refuse when no outcome matches, and Y4 of the admission design keeps a tie whose trials both consumed generated text in the refused state. The refusal is fail closed. The observed site sits past every block tie site the earlier records measured, so this is a later refusal that only a full walk past the old tie sites can reach.

### 6.2 A generated line does not match the expected line.

One case refused with this sentence, the Toon two renamed properties case.

- The aligner reports it at original line 60, the Properties block line that declares the themed color index property under a wide enum attribute. The line text is vendor shader content, so this record describes it and does not quote it.
- The sentence is the line mismatch refusal. Its fixed text lives at `Editor/Semantics/Poiyomi/PoiyomiLockedSourceAlignment.cs:49`. The walk throws it from several comparison sites. A Properties line comparison that matches neither the plain edited line nor its renamed form throws inside the Properties line matcher of the same file, the method at lines 1344 to 1419. The reported sentence does not name which comparison branch fired, so the record names the matcher and its four throw sites.
- The spec rules produce this sentence. The Properties line rules accept a line only as the plain line, the renamed line, or the plain line with a renamed copy after it. The real lock wrote a variant of that line that matches none of the three. The refusal is fail closed.

### 6.3 The known declaration initializer risk did not block this run

The vendor run record of 2026-10-26 named an open risk: the real lock bakes a property use inside a local variable declaration initializer, and the aligner refuses that shape because a declaration line keeps property identifiers. No refusal of this run reported that shape. The nine block refusals sit at a Unity built in guard. The one line mismatch sits at a Properties block line. The declaration initializer shape stays an open owner decision, and no case of this run reached a program declaration line refusal.

- The lock tool was thryeditor 2.74.3 on 2026-10-27. The suite has no version gate (Y9 item 9), so a later version changes the outcomes of this record.
